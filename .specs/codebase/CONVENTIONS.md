# Conventions

## Coding Style
- Functional components with React Hooks.
- TypeScript for type safety.
- `use client` directive for components using hooks or browser APIs.

## Naming
- Components: PascalCase (e.g., `ServiceCharts.tsx`).
- Hooks: camelCase starting with `use` (e.g., `useServices.ts`).
- Types: PascalCase (e.g., `Service`).

## Styling
- Tailwind CSS v4.
- Use Unum brand color variables (e.g., `bg-unum-blue`).

## Privacy
- All tool data must remain in `localStorage`.
- No sensitive data in logs.
